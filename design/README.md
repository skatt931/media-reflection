# Дизайн Mini App

Макети з вигаданими даними (нічого з справжнього щоденника). Відкрий [mockups/index.html](mockups/index.html) у браузері; тема перемикається кнопкою вгорі праворуч або `?theme=dark`.

- **A · Editorial, день як число** — обрано, реалізовано в [miniapp/](../miniapp/). Також є екрани «Медіатеки» (список, фільтри, матеріал), яких у застосунку ще немає.
- **B · Editorial, перший рядок як заголовок** — перше речення як заголовок запису, розділи-заголовки без нижньої панелі, рік крапками. Не обрано.
- **C · Рідний Telegram** — системний шрифт і згруповані списки. Не обрано.

`mockups/shot.sh <a|b|c> <light|dark> <файл.png>` робить знімок сторінки через Chrome (macOS). Шрифт Literata (OFL) лежить у `mockups/fonts/`.
