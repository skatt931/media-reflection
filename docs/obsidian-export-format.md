# Формат експорту в Obsidian

Бот віддає zip, який розпаковується в корінь vault і містить `Журнал`-файли (`Journal/ДД.ММ.РР.md`, ідеї в `Journal/Ideas/Inbox/`) та `Медіатека/Матеріали/` з `Медіатека/Обкладинки/`. Записи щоденника й ідеї лежать як є, без frontmatter; другий запис за день має суфікс « (2)». Інші нотатки (зокрема Taste) не читаються і не змінюються.

## Нотатка матеріалу

`Медіатека/Матеріали/<назва> — <id>.md`. Ім'я файла не змінюється, навіть якщо матеріал потім перейменували.

```markdown
---
media_reflection_id: "…"
тип: "Відео"
автор: "…"
джерело: "youtube.com"
посилання: "https://…"
стан: "Ознайомився"
дата: "2026-11-04"
дата_джерело: "capture"      # capture — дата надсилання, user — вказана вручну
додано: "2026-11-04"
враження: "Сподобалось"     # Улюблене / Сподобалось / Змішані враження / Не сподобалось
tags: ["…"]                 # пробіли в тегах замінено на _: "штучний_інтелект"
сутності: ["…"]
обкладинка: "[[Медіатека/Обкладинки/<id>.jpg]]"   # якщо є
---

# Назва

![[Медіатека/Обкладинки/<id>.jpg|400]]   обкладинка зі сторінки
> текст допису чи опис зі сторінки

## Мої враження        дослівно, з датами
## Про матеріал · AI    опис від AI, якщо є
## Історія додавань     якщо надсилав кілька разів

<!-- media-reflection:personal -->
## Мої доповнення       редагуй тут, експорт це зберігає
```

## Правила

- Архів містить лише нотатки й обкладинки, яких ще не експортували. Експортоване раніше не надсилається знову, навіть якщо запис змінився: про зміну лише записується в `export_changes`.
- Усе вище за marker генерується; «Мої доповнення» в нотатці порожні, вони твої.
- Розпаковуючи, не підтверджуй заміну наявних файлів: новий архів не має їх містити.
- Запис видалено в боті: нотатка у vault лишається, у `export_changes` з'являється запис `deleted`.
- Обкладинка надсилається один раз; якщо з'явилась пізніше, приходить окремо.
- Підсумки й `Медіатека.md` не входять. Лінк `[[Медіатека/Медіатека|← Медіатека]]` у нотатці веде на сторінку, створену ранішим експортом.
- Старий запис у vault (`npm run export:vault`) діє за правилами hash/manifest і не пов'язаний з архівним обліком.
