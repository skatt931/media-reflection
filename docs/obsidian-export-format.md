# Формат експорту в Obsidian

Експорт пише лише в `<vault>/Медіатека/`. Інші нотатки (зокрема Taste) не читаються і не змінюються.

## Нотатка матеріалу

`Медіатека/Матеріали/<назва> — <id>.md`. Ім'я файла не змінюється, навіть якщо матеріал потім перейменували.

```markdown
---
media_reflection_id: "…"
тип: "Відео"
автор: "…"
джерело: "youtube.com"
посилання: "https://…"
стан: "Ознайомився"
дата: "2026-11-04"
дата_джерело: "capture"      # capture — дата надсилання, user — вказана вручну
додано: "2026-11-04"
враження: "Сподобалось"
tags: ["…"]
сутності: ["…"]
обкладинка: "[[Медіатека/Обкладинки/<id>.jpg]]"   # якщо є
---

# Назва

![[Медіатека/Обкладинки/<id>.jpg|400]]   обкладинка зі сторінки
> текст допису чи опис зі сторінки

## Мої враження        дослівно, з датами
## Про матеріал · AI    опис від AI, якщо є
## Історія додавань     якщо надсилав кілька разів

<!-- media-reflection:personal -->
## Мої доповнення       редагуй тут, експорт це зберігає
```

## Правила

- Експорт пише нові та змінені матеріали, незмінені пропускає.
- Усе вище за marker генерується. Якщо там є ручні правки (hash не збігається), файл не перезаписується і потрапляє у звіт як конфлікт.
- Файл, якого немає в manifest, не перезаписується.
- Запис атомарний: тимчасовий файл → rename. Перерваний експорт добирається наступним запуском (`vault_pending` → `vault_exports` у SQLite).
- Symlink і шляхи поза vault відхиляються.
- Обкладинки копіюються в `Медіатека/Обкладинки/` один раз і не перезаписуються.
- Запис видалено в боті → експорт видаляє його нотатку й обкладинку, якщо hash збігається і «Мої доповнення» порожні. Інакше нотатка лишається і потрапляє у звіт.
- `Медіатека.md` — звичайний Markdown без плагінів: посилання на підсумки, останні, на потім, сподобалось, без вражень.
- `Підсумки/<рік-місяць>.md` і `Підсумки/<рік>.md` — ті самі слайди, що й у боті, з посиланнями на нотатки матеріалів. Ті самі правила hash і конфліктів; поточний місяць оновлюється кожним експортом.
