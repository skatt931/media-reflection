## Діє зараз

| Тема | Рішення |
|---|---|
| Запуск | Hetzner CPX02 (Nuremberg), Node 24 LTS з офіційного архіву в `/usr/local`, systemd-сервіс `media-reflection` ([deploy/media-reflection.service](../deploy/media-reflection.service)), Telegram long polling. Вхід по SSH лише за ключем, без root і паролів; firewall ufw (лише SSH), Tailscale для приватного доступу. Mac — лише для розробки: другий екземпляр бота з тим самим токеном запускати не можна. launchd-сервіс (`scripts/service.mjs`) лишається для запуску на Mac, зараз не використовується. Без n8n, React |
| Сховище | SQLite — єдине джерело правди. Obsidian — читабельна копія за ручним експортом. Для AI-пошуку змінювати БД не потрібно: якість залежить від тегів і відбору, а векторний пошук за потреби додається в SQLite (sqlite-vec) |
| Доступ | Лише власник (TELEGRAM_USER_ID), лише приватний чат. Токени в `.env` поза Git |
| Capture | Одна URL на повідомлення. Текст поруч — перше враження. Однакова URL без tracking-параметрів → той самий матеріал, нова подія capture. Посилання під текстом читається з entities |
| На потім | Кнопка «На потім» на картці (toggle; вихід — «Ознайомився» сьогодні). Коментар лише «потім» / «на потім» / «later» / 🔖 поруч із посиланням або одразу після нього (≤10 хв) — «На потім» без думки. Без AI-вгадування наміру. «На потім» не потрапляє в «Без вражень» |
| Ресурс | Тип «Ресурс»: сайт, інструмент, галерея, довідник для повторного використання. Автоматично: головна сторінка сайту, Dribbble, Behance, Awwwards, GitHub, Product Hunt, Figma Community; також AI. Без стану й дати: автоматичні «Ознайомився» + дата знімаються, ручні — ні; при зміні типу назад повертаються. Не в «Без вражень» і не в лічильнику тижня |
| Короткий коментар | ≤80 символів, протягом 10 хв після посилання без коментаря → думка до нього, з кнопкою «Це окремий запис» |
| Стани | Новий запис — «Ознайомився» з датою надсилання (позначена як автоматична). Також «На потім», «У процесі», «Завершено». Старі записи не змінюються |
| Реакція | ❤️ / 👍 / 😐 / 👎 прямо під карткою, повторний дотик прибирає. ❤️ («Улюблене») — рідкісна найвища позначка; у фільтрах і статистиці рахується як «сподобалось». Реакція рахується відповіддю на запит рефлексії. Числової оцінки 1–5/1–10 немає свідомо: зайве тертя, оцінки «пливуть», нюанс — у думках |
| Кнопки | Під карткою: реакції, «Додати думку», «Змінити». Підменю редагують ту саму картку |
| Списки | Одне повідомлення на список, гортається ← →, без фото (щоб його можна було редагувати). Стан списку — в SQLite за message id, зберігаються останні 50 |
| Видалення | «Змінити» → «Видалити» → підтвердження. Видаляє запис, події, враження й локальну обкладинку. Нотатку в Obsidian прибирає наступний експорт, лише якщо її не редагували вручну |
| Переслане | Пересланий пост — матеріал, його текст не стає враженням. Посилання під текстом (text_link) читається з entities |
| Метадані | Open Graph сторінки (UA `facebookexternalhit/1.1`), YouTube через oEmbed. Розгортання redirect із перевіркою кожного кроку, блок приватних адрес. Обкладинка зберігається локально й показується в картці |
| AI | Groq Free, `openai/gpt-oss-120b`, strict JSON. Автоматично: тип, 3–6 тегів, ≤8 назв, опис українською. Без підтвердження. Ручні поля AI не перезаписує. Назва й автор — лише дослівно з даних сторінки, ніколи з власних думок. Порожня відповідь AI не стирає попередніх тегів |
| Уточнення | Максимум одне необов'язкове AI-питання на діалог |
| Голос | Groq Whisper `whisper-large-v3-turbo`, мова `uk` за замовчуванням. Аудіо передається в Groq |
| Підсумок тижня | П'ятниця 18:00 (WEEKLY_DIGEST, TIMEZONE Europe/Prague). Одне повідомлення без звуку: кількість збереженого за типами, кількість без вражень, кнопка «Переглянути». Нічого нового — нічого не надсилаємо. Невідкритий підсумок оновлюється, а не дублюється. Таймер усередині процесу бота |
| Підсумки | Місяць — 1-го о MONTHLY_REVIEW (10:00), рік — у січні. Одне повідомлення без звуку зі слайдами ← →, порожній період не надсилається; `/review [YYYY-MM\|YYYY]` на вимогу. Слайди: що збережено (типи, джерела, зміна міксу), що сподобалось (смак за типами від 3 реакцій), теми й нові теми, імена в різних типах, автори, звички (день і час, повтори, кількість думок), «На потім». Рік: помісячно, перший і останній. Рахується локально. Ті самі підсумки — в Obsidian `Медіатека/Підсумки/` |
| Історія змін | Таблиця `events` пише ручні зміни status / reaction / type з датою. Потрібна для аналітики; заднім числом не відновлюється |
| Пошук | LLM перетворює запит на фільтри й синоніми → локальний відбір ≤30 записів, що пройшли фільтри (спершу збіг слів за основою, без закінчень) → LLM обирає й за змістом → лише перевірені ID. Фільтр типу лишається, тільки якщо тип названо в запиті («ресурси», «музика» = трек + альбом). Без embeddings. Без Groq — пошук за словами, ≤10 |
| Теги | Слова з пробілами, нижній регістр; в Obsidian — з `_`. 3–6 на запис, від загального до конкретного. AI отримує до 80 наявних тегів і повторно використовує їх. Версія AI-запиту в `ai_done`: `/enrich` переробляє записи старішої версії, ручні теги не чіпає |
| Довідка | `/help` — одне повідомлення з темами-кнопками, текст міняється на місці. Приклади — реальні сценарії, а не тестові |
| За типом | «Бібліотека» → «За типом»: лише наявні типи з кількістю → звичайний список зі стрілками |
| Obsidian | Окрема папка `Медіатека` у vault `essential`. Одна нотатка на матеріал з усіма враженнями. Розділ «Мої доповнення» зберігається. Ручні правки решти → конфлікт без перезапису. Taste не чіпаємо й не імпортуємо |
| Ідеї та щоденник (узгоджено 2026-11-08, не реалізовано) | Дві окремі сутності, не частина медіатеки: не потрапляють у «Без вражень», підсумки тижня/місяця/року й пошук по матеріалах. **Щоденник**: бот лише збирає текст і віддає у vault, читання й редагування — в Obsidian (джерело правди для редагування). Окрема SQLite-БД (незалежні backup і доступ). Існуючий щоденник з Obsidian імпортується. Без AI-обробки за замовчуванням; голосові в Groq — лише за явним вибором. Без нагадувань: ритм раз на тиждень або рідше. Довгий текст через режим збору кількох повідомлень (ліміт Telegram ~4096 символів). **Передумова:** backup запущено й перевірено до першого запису щоденника |
| Міграції | Адитивні. PRAGMA user_version=3, backup `.pre-v3.sqlite` перед першою міграцією. Старі ручні поля консервативно заблоковані від AI |

## Історія

- **2026-11-04 — локальний PoC.** Capture, `/reflect`, `/list`, JSON/Markdown snapshot. Без AI.
- **2026-11-04 — кнопки й Groq.** Стани, реакції, редагування полів, контекст діалогу, AI-пропозиції з підтвердженням.
- **2026-11-04 — автоматизація.** AI застосовується без підтвердження. Дефолт «Ознайомився». Розмовний пошук. Ручний incremental export в окрему Медіатеку, без прив'язки до Taste.
- **2026-11-04 — якість даних і рефлексія.** Нормалізація URL, Open Graph і обкладинки, злиття share-посилань, `/enrich`, реакції на картці, редагування на місці, короткі коментарі, голосові, ранкова добірка, launchd-сервіс. Виправлено: AI брав назву з тексту думки і стирав теги порожньою відповіддю.
- **2026-11-05 — менше повідомлень.** Щоденну добірку з окремою карткою на кожен запис замінено одним тижневим підсумком. Списки стали одним повідомленням зі стрілками. Прибрано «Пропустити» й «Відкласти до завтра». Додано видалення, посилання під текстом, переслані пости, меню команд.
- **2026-11-05 — аналітика.** Підсумки місяця й року в боті та Obsidian, журнал змін `events`. «Звичка рефлексії» — не окремий слайд, а один рядок у «Звичках».
- **2026-11-05 — ❤️.** Четверта реакція «Улюблене» замість шкали 1–10: дає топ місяця/року (слайд «Улюблене ❤️») без зайвих рішень при кожній оцінці.
- **2026-11-05 — ресурси й «На потім».** Тип «Ресурс», кнопка й ключові слова «На потім». «Без вражень» більше не включає «На потім» і ресурси.
- **2026-11-05 — пошук і довідка.** «За типом» у бібліотеці, `/help` з темами. Виправлено: фільтр типу губився для «ресурси» й «музика»; теги з `_` не знаходились за фразою. Пошук за основою слова, до 30 кандидатів для AI, 3–6 тегів зі словником наявних. SQLite лишається: Supabase — теж SQL (Postgres), його AI-перевага — pgvector, аналог якого є для SQLite.
- **2026-11-08 — хостинг.** Перенос з Mac на VPS: Hetzner Cloud CPX02 (1 vCPU AMD, 1 ГБ RAM, 20 ГБ, Nuremberg, Ubuntu LTS), близько €7.85/міс із VAT і IPv4. Cost-Optimized (CX23/CAX11) був недоступний. Обрано замість Fly.io: простіше Tailscale, без Docker, SQLite у звичайному файлі. Доступ до майбутнього веб-UI — через Tailscale (без публічного URL), без власного логіну. Порядок: сервер і backup → веб-UI лише для перегляду. Ціни перевірені за консоллю Hetzner. 2026-11-08 бот і БД (23 матеріали) перенесені на сервер, перевірені контрольною сумою; бот ≈130 МБ RAM, ≈670 МБ вільно, диск 15 ГБ вільно. Відповідь бота в Telegram підтверджена.

## Відкрито

- Автодеплой (обрано 2026-11-08, код у репозиторії, на сервері не ввімкнено): push у `main` → GitHub Actions (`npm run check`, `npm test`, [.github/workflows/deploy.yml](../.github/workflows/deploy.yml)) → SSH → [deploy/deploy.sh](../deploy/deploy.sh): fast-forward до протестованого sha, знімок `data/media.sqlite.pre-deploy`, перезапуск, перевірка через 15 с, відкат при збої. Залишилось налаштувати сервер: (1) код на сервері скопійований, не clone: `git init`, `git remote add origin`, `git fetch`, `git reset --hard origin/main` (`.env` і `data/` у `.gitignore`), з read-only deploy key для GitHub; (2) окремий SSH-ключ для Actions у `authorized_keys` з `command="/home/ihor/media-reflection/deploy/deploy.sh",restrict`; (3) `/etc/sudoers.d/media-reflection`: `ihor ALL=(root) NOPASSWD: /usr/bin/systemctl restart media-reflection`; (4) секрети GitHub `DEPLOY_SSH_KEY`, `DEPLOY_KNOWN_HOSTS`, `DEPLOY_HOST`, `DEPLOY_USER`; (5) branch protection на `main`, бо push у `main` виконує код на сервері. Відкат повертає код, але не схему SQLite: для цього `pre-deploy` знімок.
- Backup (обрано 2026-11-08, код у репозиторії, не заплановано): сервер → Mac через Tailscale/SSH ([scripts/backup.mjs](../scripts/backup.mjs)), раз на 7 днів, 12 копій у `~/Backups/media-reflection/`, узгоджений знімок `VACUUM INTO` + `covers/`, перевірка `integrity_check` перед збереженням, `.env` не копіюється. Слабке місце: копія з'являється, лише коли Mac увімкнений і в мережі Tailscale; зовнішнього сховища (B2/R2, зашифровано) немає. Увімкнення: `BACKUP_HOST` у `.env` на Mac, `npm run backup`, потім `npm run backup:install`.
- Obsidian-експорт після переносу: БД із обліком експорту (`vault_exports`, `vault_pending`) тепер на сервері, а vault — на Mac. Потрібен спосіб запускати експорт без розходження обліку (наприклад, синхронізація папки `Медіатека`).
- Ідеї (memory dump): точна форма не узгоджена. Пропозиція: команда `/idea текст` або кнопка в меню, один рядок без діалогу, відповідь реакцією ✓, `/ideas` зі списком зі стрілками, окрема нотатка або файл на день у Obsidian. Чи окрема БД, як у щоденника, — не вирішено.
- Щоденник: формат наявних нотаток в Obsidian (файл на день чи один файл, frontmatter, назви) — для імпорту; режим збору (`/diary`, «Готово» чи таймаут), дата запису заднім числом; як щоденник потрапляє у vault, коли БД на сервері, а vault на Mac (та сама проблема, що й в експорту Медіатеки); чи показувати один рядок «останній запис — N днів тому» в тижневому підсумку.
- Оновлення Node на сервері вручну (архів із перевіркою суми); автоматичні оновлення ОС налаштовано, Node у них не входить.
- Імпорт Taste, двосторонні правки з Obsidian.
- Embeddings / семантичний пошук (sqlite-vec у тій самій БД). Потребує окремого провайдера embeddings — у Groq його немає. Повернутися, коли записів буде ~1000 або пошук за 30 кандидатами перестане вистачати.
- Веб-інтерфейс / PWA для перегляду бібліотеки з телефона і його захист. Наступний крок після бота; аналітика з `src/stats.ts` переїде туди з графіками.
- Тривалість матеріалів (години відео/музики) і фіксований словник тем — для точніших підсумків.
